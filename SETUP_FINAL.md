## 🎯 Что нужно сделать:

### 1️⃣ Замени аватарку класса (1 минута)

1. Возьми изображение с аватаркой класса (тот что ты прислал)
2. Переименуй в `class-avatar.jpg`
3. Положи в ту же папку, где `index.html`
4. **Или** используй ссылку на изображение из интернета

**Альтернатива:** Если не хочешь загружать файл, код автоматически покажет заглушку с "7H"

### 2️⃣ Настрой Firebase (3 минуты)

**Если ещё не настроил:**

1. Создай проект на https://console.firebase.google.com/
2. Включи **Realtime Database** (уже есть у тебя)
3. Включи **Firebase Storage** (для PDF файлов)
   - Инструкция в `FIREBASE_STORAGE_SETUP.md`
4. Скопируй конфигурацию
5. Замени в `app.js` строки 13-20

### 3️⃣ Настрой правила безопасности (2 минуты)

**Realtime Database Rules:**
```json
{
  "rules": {
    "news": {
      ".read": true,
      ".write": true
    },
    "materials": {
      ".read": true,
      ".write": true
    }
  }
}
```

**Storage Rules:** (см. `FIREBASE_STORAGE_SETUP.md`)

### 4️⃣ Опубликуй на GitHub Pages (5 минут)

1. Создай репозиторий на GitHub
2. Загрузи все файлы
3. Settings → Pages → Deploy from branch → main
4. Готово!

## 🆘 Решение проблем:

### Аватарка не отображается:
1. Проверь, что файл называется `class-avatar.jpg`
2. Или положи изображение с другим именем и измени путь в `index.html`
3. Или используй онлайн ссылку: `<img src="https://ссылка-на-фото.jpg">`

### Таймер не работает:
1. Открой консоль браузера (F12)
2. Проверь ошибки
3. Убедись, что JavaScript включён

### Файлы не загружаются:
1. Проверь, что Firebase Storage включён
2. Проверь правила Storage Rules
3. Убедись, что файл меньше 10 МБ
