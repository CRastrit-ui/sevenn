# 🔐 Инструкция по безопасности пароля

## Как работает защита

Пароль `065860` НЕ хранится в коде в открытом виде. Вместо этого используется его SHA-256 хеш.

## Принцип работы

1. При вводе пароля пользователь вводит текст в поле
2. JavaScript вычисляет SHA-256 хеш от введённого пароля через Web Crypto API
3. Полученный хеш сравнивается с эталонным хешем
4. Если хеши совпадают - доступ разрешён

## Почему это безопасно?

1. ✅ В коде нет пароля в открытом виде
2. ✅ SHA-256 - необратимая функция (нельзя получить пароль из хеша)
3. ✅ Хеширование происходит на клиенте через Web Crypto API
4. ✅ Даже при просмотре кода через "Inspect Element" пароль не виден

## Дополнительные меры защиты (рекомендуется)

### 1. Firebase Authentication (наилучший вариант)

```javascript
// Вместо проверки пароля используйте Firebase Auth
import { getAuth, signInWithEmailAndPassword } from 'firebase/auth';

const auth = getAuth(app);
const userCredential = await signInWithEmailAndPassword(
    auth, 
    'admin@example.com', 
    'your-secure-password'
);
```

### 2. Измените хеш пароля

Если хотите поменять пароль:

1. Перейдите на сайт: https://emn178.github.io/online-tools/sha256.html
2. Введите новый пароль
3. Скопируйте SHA-256 хеш
4. Замените значение `PASSWORD_HASH` в `app.js`

### 3. Ограничьте доступ по IP (через Cloudflare)

Если используете Cloudflare:
1. Включите "Under Attack Mode"
2. Настройте Page Rules для защиты админ-панели

## Что НЕ защищено

⚠️ **Важно понимать ограничения:**

1. При должной настойчивости хеш можно найти в коде
2. Квалифицированный программист может подобрать пароль
3. Для реальной защиты нужен серверный бэкенд

## Рекомендации

- Для школьного проекта текущей защиты достаточно
- Если нужна максимальная безопасность - используйте Firebase Auth
- Регулярно меняйте пароль
- Не передавайте пароль посторонним
