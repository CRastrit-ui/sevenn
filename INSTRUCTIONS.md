# 📋 Пошаговая инструкция по настройке сайта

## Шаг 1: Создайте проект Firebase (5 минут)

1. Откройте https://console.firebase.google.com/
2. Нажмите **"Add project"**
3. Введите название проекта (например, `7n-class`)
4. Нажмите **"Continue"**
5. Отключите Google Analytics (не нужно)
6. Нажмите **"Create project"**
7. Дождитесь создания (30 секунд)

## Шаг 2: Создайте базу данных Firestore (2 минуты)

1. В меню слева выберите **"Firestore Database"**
2. Нажмите **"Create database"**
3. Выберите **"Start in test mode"**
4. Нажмите **"Next"**
5. Выберите локацию: **europe-west** (Бельгия) или **asia-south1** (Индия)
6. Нажмите **"Enable"**
7. Дождитесь создания (1-2 минуты)

## Шаг 3: Создайте хранилище файлов Storage (2 минуты)

1. В меню слева выберите **"Storage"**
2. Нажмите **"Get started"**
3. Выберите **"Start in test mode"**
4. Нажмите **"Next"**
5. Выберите ту же локацию, что и для Firestore
6. Нажмите **"Done"**

## Шаг 4: Получите конфигурацию проекта (2 минуты)

1. Нажмите на **шестерёнку ⚙️** рядом с "Project overview"
2. Выберите **"Project settings"**
3. Прокрутите вниз до раздела **"Your apps"**
4. Нажмите на иконку **web `</>`**
5. Введите название приложения (например, "7Н Класс")
6. Поставьте галочку **"Also set up for Firebase Hosting"**
7. Нажмите **"Register app"**
8. Скопируйте конфигурацию (блок `const firebaseConfig = {...}`)

## Шаг 6: Настройте правила безопасности (2 минуты)

### Firestore Rules:

1. В Firebase Console перейдите в **"Firestore Database"** → **"Rules"**
2. Замените весь код на:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /news/{newsId} {
      allow read: if true;
      allow write: if request.time > timestamp.date(2024, 1, 1);
    }
    match /materials/{materialId} {
      allow read: if true;
      allow write: if request.time > timestamp.date(2024, 1, 1);
    }
  }
}
```

3. Нажмите **"Publish"**

### Storage Rules:

1. В Firebase Console перейдите в **"Storage"** → **"Rules"**
2. Замените весь код на:

```javascript
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /materials/{allPaths=**} {
      allow read: if true;
      allow write: if request.time > timestamp.date(2024, 1, 1);
    }
  }
}
```

3. Нажмите **"Publish"**

**Почему `request.time > timestamp.date(2024, 1, 1)`?**
Это временное решение - правила работают только после 1 января 2024 года, что защищает от случайного создания данных до настройки.

## Шаг 7: Загрузите файлы на GitHub (5 минут)

### Создайте репозиторий:

1. Откройте https://github.com/
2. Если нет аккаунта - создайте (бесплатно)
3. Нажмите **"+"** в правом верхнем углу → **"New repository"**
4. Введите имя: `7n-class` (или любое другое)
5. Оставьте **"Public"**
6. **НЕ ставьте** галочки "Add README", ".gitignore", "license"
7. Нажмите **"Create repository"**

### Загрузите файлы:

1. Нажмите **"uploading an existing file"**
2. Перетащите 4 файла:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `README.md`
3. Введите сообщение: "Initial commit"
4. Нажмите **"Commit changes"**

### Включите GitHub Pages:

1. Перейдите в **"Settings"** репозитория
2. В меню слева выберите **"Pages"**
3. В разделе **"Build and deployment"** → **"Source"** выберите **"Deploy from a branch"**
4. В разделе **"Branch"** выберите:
   - Branch: **main** (или master)
   - Folder: **/ (root)**
5. Нажмите **"Save"**
6. Подождите 2-3 минуты
7. Ваш сайт будет доступен по адресу: `https://ваш-username.github.io/7n-class/`

## 🔧 Решение проблем

### Ошибка: "Firebase: No Firebase App '[DEFAULT]' has been created"

**Причина:** Не настроена Firebase конфигурация

**Решение:**
1. Проверьте, что в `app.js` заменена конфигурация Firebase
2. Убедитесь, что скопировали ВСЕ поля из `firebaseConfig`

### Ошибка: "Permission denied"

**Причина:** Неправильные правила Firestore или Storage

**Решение:**
1. Проверьте правила в Firestore Database → Rules
2. Проверьте правила в Storage → Rules
3. Нажмите "Publish" после изменений

### Ошибка: "Failed to fetch"

**Причина:** Firebase ещё не инициализирован или нет интернета

**Решение:**
1. Проверьте подключение к интернету
2. Откройте консоль браузера (F12) и посмотрите ошибки
3. Убедитесь, что файлы загружены на GitHub Pages

### Сайт не обновляется после изменений

**Решение:**
1. Обновите страницу с принудительной перезагрузкой: `Ctrl + Shift + R` (Windows) или `Cmd + Shift + R` (Mac)
2. Очистите кэш браузера
3. Подождите 5 минут - GitHub Pages может обновляться до 5 минут
